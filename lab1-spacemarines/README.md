# Космодесантники — информационная система

Spring MVC (Spring Boot) + Hibernate (JPA) + PostgreSQL. Фронтенд — статические страницы на чистом JS.

## Запуск

Требуется Java 17+ и Maven. Параметры БД (кафедральный сервер: хост `pg`, база `studs`) задаются переменными окружения:

```bash
export DB_USER=sXXXXXX
export DB_PASSWORD=...
mvn spring-boot:run
```

По умолчанию `DB_HOST=pg`, `DB_PORT=5432`, `DB_NAME=studs`. Если с локальной машины хост `pg` недоступен, пробросьте порт через SSH на кафедральный сервер и укажите `DB_HOST=localhost`.

Приложение открывается на http://localhost:8080. Сначала зарегистрируйтесь («Регистрация» на странице входа).
Таблицы создаются автоматически из `src/main/resources/schema.sql`.

## Структура

| Пакет | Назначение |
|---|---|
| `model` | JPA-сущности (`SpaceMarine`, `Chapter`, `Coordinates`, `AppUser`) и enum'ы |
| `repository` | Spring Data JPA репозитории |
| `service` | Бизнес-логика, валидация, специальные операции |
| `web` | REST-контроллеры (Spring MVC) |
| `dto`, `error`, `event`, `config` | DTO, ошибки, SSE-рассылка изменений, безопасность |

## Соответствие заданию

- CRUD в отдельных окнах: создание/изменение — диалог, информация по ID (с орденом) — диалог, удаление — подтверждение.
- Таблица: пагинация, сортировка по любой колонке, фильтры по неполному совпадению для строковых колонок — на сервере.
- Синхронизация между пользователями: Server-Sent Events (`/api/events`), события отправляются после коммита транзакции.
- Роспуск/удаление ордена: связанные десантники переводятся в другой орден по выбору пользователя.
- Специальные операции (страница «Спецоперации») реализованы в `SpecialOperationsService` / `ChapterService` на Java, без функций БД.
- Ограничения полей: Bean Validation + проверки в сущности (ORM), `CHECK`/`NOT NULL`/`FK` в `schema.sql` (БД), понятные сообщения в `MarineValidator`.
